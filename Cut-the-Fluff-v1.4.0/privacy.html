Privacy Policy

Effective September 16, 2026

Cut the Fluff is a browser extension that rewrites selected or pasted text and can review visible page text for writing patterns. It does not operate a developer-owned text-processing server and does not sell personal data.

Data the extension handles

  • Text you paste, select, or submit for rewriting.
  • Bounded samples of visible page text when you turn on Writing-pattern scan.
  • Your chosen provider, model, scan threshold, rewrite style, current draft, and provider API key.

How data is used

Rewrite text is sent directly from your browser to the AI provider you select: Anthropic, OpenAI, or Google Gemini. When Writing-pattern scan is enabled, bounded visible-text samples are also sent directly to that provider for style analysis. The provider's privacy policy and terms apply to those requests.

Storage and sharing

Your API key and preferences are stored in Chrome's local extension storage for your browser profile. The extension developer does not receive your page text, rewrite text, or API key. Cut the Fluff does not sell data or use it for advertising.

Your controls

The extension reads the active tab only when you use a feature that needs it. Scanning is off until you enable it for a tab. You can remove the saved API key, draft, and preferences from Settings, or remove extension-local data by uninstalling the extension.

Changes

If the product's data handling changes, this policy will be updated before the changed version is released.

Questions

Use the support contact shown on Cut the Fluff's Chrome Web Store listing for privacy questions.
