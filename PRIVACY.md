# Cut the Fluff — Privacy Policy

Effective: September 16, 2026

Cut the Fluff does not operate a developer-owned server and does not sell user data.

- The extension reads text only when the user invokes a rewrite, asks it to use a page selection, or enables the writing-pattern scan for the current tab.
- When scanning is enabled, bounded visible-text samples are sent directly to the selected AI provider for writing-style analysis. Scan results are signals, not proof of authorship.
- Rewritten text is sent directly to the AI provider selected by the user: Anthropic, OpenAI, or Google Gemini.
- The chosen provider's own terms and privacy policy apply to those requests.
- The API key, provider choice, preferences, and current draft are stored in Chrome's local extension storage on the user's browser profile.
- Page text and rewrite results are not transmitted to the extension developer.

Users can remove the stored API key, draft, and preferences at any time from Settings. Uninstalling the extension also removes extension-local data according to Chrome's normal behavior.

Cut the Fluff is made by MOB. If the product's data handling changes, this policy must be updated before the changed version is released.
