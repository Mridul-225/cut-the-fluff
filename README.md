Cut the Fluff 1.4.0
A privacy-conscious Chrome extension that rewrites wordy text into clearer, more natural writing.

Install locally
Open chrome://extensions.
Enable Developer mode.
Choose Load unpacked and select this folder.
Add an API key on the Settings page. Click the extension icon to open its persistent side panel, select text and right-click, or press Alt+Shift+F (Command+Shift+F on macOS).
The shortcut is visible and customizable from Settings. Chrome manages assignments at chrome://extensions/shortcuts.

Rewrite styles
Human: natural, direct writing that preserves every detail.
Professional: polished work or academic writing that preserves every detail.
Shorten: a complete but more concise version.
The side panel stays open while you work and automatically follows new page selections. Rich selections retain supported bold, italic, code, line-break, heading, and list formatting.

In the side panel, press Enter to rewrite or Shift+Enter to insert a new line.

Launch notes
The extension requests access only to the active tab and the three supported API domains.
The page scan is deliberately described as a writing-pattern signal, not an AI detector.
Users supply their own provider key. For mass-market adoption, a future hosted plan with authentication, quotas, billing, abuse controls, and a published privacy policy would remove this onboarding hurdle.
